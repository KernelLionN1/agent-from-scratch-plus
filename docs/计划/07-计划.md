## 阶段二：文档处理 + 简易 RAG（2h）

> 目标：上传 PDF/Word → 解析文本 → 关键词检索 → 注入上下文

- [ ] 文本分块：按段落切分，每块 ≤ 512 tokens
- [ ] 关键词匹配检索：问题拆词 → 匹配度排序 → 取 Top 3

**产出：** `src/document_processor.py`、`test/test_day7_phase2.py`

**简化方案（不用向量库）：**
```python
chunks = split_text(pdf_text, chunk_size=512)
```

## 阶段三：text2sql 安全执行（2h）

> 目标：NL → SQL → 安全校验（只允许 SELECT）→ 只读副本 → 结果解释

- [ ] `src/text2sql.py` — Prompt 模板生成 SQL
- [ ] SQL 安全校验：正则只允许 SELECT（禁止 INSERT/UPDATE/DELETE/DROP）
- [ ] 执行：SQLAlchemy 只读连接池
- [ ] 缓存：相同问题 5 分钟 TTL

**产出：** `src/text2sql.py`、`test/test_day7_phase3.py`

**简化方案：**
```python
# 生成
sql = llm.chat(f"将问题转为SQL: {question}")

# 校验
if not re.match(r"^\s*SELECT\b", sql, re.IGNORECASE):
    raise ValueError("只允许 SELECT 查询")

# 执行
result = readonly_engine.execute(sql)

# 解释
answer = llm.chat(f"将结果翻译为自然语言: {result}")
```
