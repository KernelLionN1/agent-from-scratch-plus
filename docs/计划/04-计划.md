# Day4：LangChain + LangGraph 框架重构 每日计划

> 总时长：8h  |  目标：用手搓版所有功能，用 LangChain/LangGraph 重写一遍  
> 当日产出：框架版 Agent 系统 + 手搓 vs 框架对照

---

## 重构总览

| 手搓模块（Day1-3） | 功能 | LangChain 等价物 |
|------|------|------|
| `LLMClient` + 重试 | LLM 调用 | `ChatOpenAI` + `with_retry()` |
| `tools.py` + 注册 | 工具定义 | `@tool` 装饰器 |
| `agent.py` ReAct 循环 | Agent 执行 | `create_react_agent` + `AgentExecutor` |
| `memory.py` 截断 | 记忆管理 | `ConversationBufferMemory` / `SummaryMemory` |
| `roles.py` prompt | 角色定义 | `ChatPromptTemplate` / `SystemMessage` |
| `orchestrator.py` 编排 | 多Agent调度 | `LangGraph StateGraph` |
| `shared_state.py` | 共享状态 | `RunnableConfig` + State 图 |
| `message_bus.py` | 消息通信 | 图的 `add_edge` / `add_conditional_edge` |
| `api.py` 端点 | HTTP 服务 | 适配新架构 |
