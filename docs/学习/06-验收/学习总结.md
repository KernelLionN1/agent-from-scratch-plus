## 五、Java → Python 知识迁移

| 手写循环 → LangGraph StateGraph | Spring StateMachine → LangGraph |
| 全局 dict → Annotated[list, add] | List → List.addAll 追加 |
| print → CallbackManager | System.out → @EventListener |
| 硬编码字符串 → PromptBuilder | 字符串拼接 → Builder Pattern |
| 同步阻塞 → asyncio + await | Blocking → CompletableFuture |
| InMemory → SQLite | H2 → MySQL 持久化 |
