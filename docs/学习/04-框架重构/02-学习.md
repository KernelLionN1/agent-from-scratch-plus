## 二、tiktoken 精确计数

```python
import tiktoken
encoder = tiktoken.get_encoding("cl100k_base")  # GPT-4/DeepSeek 通用编码
tokens = encoder.encode("你好世界")
len(tokens)  # → 4（精确）
# 手搓估算: 4 // 2 = 2（严重低估）
```

**对比：**

| 内容 | 手搓估算 | tiktoken 精确 |
|------|:--:|:--:|
| "hello world" (11字符) | 5 | 2 |
| "你好世界" (4字符) | 2 | 4 |
| 中英混合 | 偏差大 | 精确 |

## 四、记忆持久化方案

```
当前: InMemoryChatMessageHistory → 进程重启 = 数据消失
改一行: SQLChatMessageHistory    → SQLite/MySQL/PostgreSQL 持久化
```

| 策略 | 做法 | 场景 |
|------|------|------|
| 全量入库 | 每条消息存一行，按 session_id 分区 | 客服、审计追溯 |
| 摘要压缩 | LLM 对旧消息做摘要，只保留最近 N 轮原文 | 长对话、成本敏感 |
| 滑动窗口+入库 | 内存保留最近 N 轮，旧消息全量落库 | 混合方案 |

LangChain 换后端只需改一行 `import`，接口完全一致。Day5 工程化阶段落地。
