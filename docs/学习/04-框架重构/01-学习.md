## 一、三个模块的替换对照

### llm_client.py

```
手搓版                         框架版
─────────────────────────────────────────────
openai.OpenAI                  ChatOpenAI(base_url=DeepSeek)
手动指数退避 retry             max_retries=3 (内置)
同步 chat() 阻塞               chat() + ainvoke() 原生 async
自定义 dict 返回               AIMessage 结构化对象
_parse_chat_response()         不需要了
```

### tools.py

```
手搓版                         框架版
─────────────────────────────────────────────
手动 JSON Schema dict          @tool 装饰器自动生成
TOOL_REGISTRY 全局注册          get_langchain_tools()
execute_tool() 手动调用        AgentExecutor 自动调用
```

### agent.py

```
手搓版                         框架版
─────────────────────────────────────────────
while True: 手动循环            AgentExecutor.invoke() 一行
手动 iteration 计数              max_iterations 参数
手动消息构建 (role/content)     ChatPromptTemplate
手动 tool_calls 解析             AgentExecutor 内置
手动 keep_going 判断            框架自动
```

**代码量对比：** agent.py 的 run() 从 70 行 → 15 行

## 二、关键概念

### ChatOpenAI
```python
from langchain_openai import ChatOpenAI
llm = ChatOpenAI(model="deepseek-chat", base_url="https://api.deepseek.com")
response = llm.invoke([HumanMessage("你好")])  # 同步
response = await llm.ainvoke([...])            # 异步（原生！）
```

### AgentExecutor
```python
executor = AgentExecutor(agent=agent, tools=tools, max_iterations=10)
result = executor.invoke({"input": "计算 1+2"})
# 框架自动完成：调LLM→解析tool_call→执行工具→反馈结果→判断是否继续
```

## 四、模块加载时 `print` 的执行时机

```python
# tools.py 最后一行
print(f"[tools] 已注册 {len(TOOL_REGISTRY)} 个工具: {list_tools()}")
```

只要 `import src.tools`（或任何从 tools 导入的语句），这行 `print` 就会执行。

**Python 模块加载机制：** `import` 时，Python 从头到尾执行整个文件。所有不在函数/类里的代码都会在 import 时运行一次（且仅一次，后续 import 走缓存）。

```python
# 不管从哪里导入，都会触发 print
from src.tools import calculator   # 触发
import src.tools                    # 触发（首次）
import src.tools                    # 不触发（已缓存）
```

**Java 对比：**

| Python | Java |
|--------|------|
| 模块级代码 `import` 时执行 | 只有静态块 `static {}` 在类加载时执行 |
| `print()` → 日志刷屏 | `System.out` 同样刷屏，用 `Logger` 控制 |

## 五、`inspect.getsource` 反射拿源码

```python
import inspect
source = inspect.getsource(ReActAgent.run)
assert "_agent.invoke" in source   # 验证实现确实用了框架
```

不是切面（AOP），是**反射**——把函数源码读成字符串，然后做内容检查。用于测试中验证"重构后底层实现确实换了"，防止"功能跑通了但底层还是手搓"的情况。

| Python | Java |
|--------|------|
| `inspect.getsource(fn)` | 无直接等价，需用 `Method` 反射拿签名/注解 |
| 拿的是源码字符串 | 拿的是字节码/方法元数据 |
