# Day4 学习总结：LangChain + LangGraph 框架重构

> 分支：`04-langchain-refactor` | 4 阶段 | 核心：手搓 → 框架

---

## 一、Day4 做了什么

```
手搓版（Day1-3）                  框架版（Day4）              代码变化
──────────────────────────────────────────────────────────────────
LLMClient + 手动重试              ChatOpenAI + 内置重试         70行 → 50行
TOOL_REGISTRY + 手动 Schema       @tool + get_langchain_tools   保留兼容
while True + 手动循环             create_agent + invoke()      70行 → 15行
ConversationMemory + 估算         InMemoryChatMessageHistory    220行 → 180行
  len//2 token 估算               tiktoken 精确计数             
Orchestrator + MessageBus         StateGraph 一张图            720行 → 240行
  + SharedState (3个模块)          替代全部                     
api.py                            api.py                       0 行改动
```

## 二、核心洞察

| 洞察 | 说明 |
|------|------|
| 接口不变，实现随便换 | api.py 零改动就是封装的全部意义 |
| 框架不是魔法 | create_agent 内部还是调 LLM + 解析 tool_calls，和你手搓的一样 |
| 一张图替代三个模块 | StateGraph 把控制流+通信+共享状态统一为一个概念 |
| Day4 用的是固定工作流 | 边的方向程序员写死，不是 LLM 自主路由 |
| tiktoken 精确 ≠ 手搓估算 | 中文 token 从严重低估 → 精确 |

## 三、Day4 vs Day5 预告

```
Day4（框架替换）:                      Day5（动态路由）:
  graph.add_edge("A", "B")             should_continue(state) → LLM 决定
  程序员决定流程                         LLM 自己决定下一步
  等价 Spring StateMachine             等价真正的自主 Agent
```

## 四、LangSmith

LangSmith 是 LangChain 生态的可观测平台（调用链追踪、成本监控、调试回放）。Day4 没有做，因为：
- 需要注册 LangSmith 账号 + API Key
- 核心功能（trace）可以用 Python 原生 logging 替代
- 更适合 Day6 验收时作为"生产环境补充"快速过一遍

如果想加，Day6 花半小时接入：`export LANGCHAIN_TRACING_V2=true` 一行环境变量即可自动 trace 所有 LLM 调用。
