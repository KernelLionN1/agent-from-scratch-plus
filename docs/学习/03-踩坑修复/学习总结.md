## 一、Day3 做了什么

```
Day3 不是写新功能，而是把 Day1+2 的原型加固到可用的程度。

修复前后对比：
  安全性：eval() 可执行任意代码 → 白名单校验 + 受限命名空间
  稳定性：API 裸调一次失败=崩溃 → 指数退避重试
  并发：全局 agent 内存污染 → 请求级隔离
  异常：每个端点手写 try/except → 全局异常处理器（AOP）
  角色：Prompt 模糊导致越权 → 固定格式 + 禁止项
  消息：重复消费 + 无去重 → 增量 offset + 指纹去重
```

## 三、技术栈全景

```
Day3 核心技术：
├── 安全:     白名单正则 + __builtins__={}
├── 异步:     async/await + asyncio.to_thread + asyncio.wait + wait_for
├── 容错:     指数退避重试 + return_exceptions + 乐观锁重试
├── 并发:     请求级实例 + threading.Lock + 深拷贝隔离
├── 消息:     增量 offset + sender|type|content 指纹去重 + 阻塞等待
├── AOP:      @app.exception_handler → TimeoutError/Exception 统一接管
└── Prompt:   固定格式 + 禁止项 + 结构化输出
```
