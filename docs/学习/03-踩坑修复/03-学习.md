## 二、代码块提取（#21）

```python
def _extract_code_block(text: str) -> str:
    """正则提取 ```python ... ``` 代码块，无标记则返回原文"""
    match = re.search(r'```(?:python)?\s*\n(.*?)```', text, re.DOTALL)
    return match.group(1).strip() if match else text.strip()
```
