## 一、新增端点

### 1.1 POST /chat/orchestrate — 多 Agent 编排入口

```
支持两种模式：
  mode=serial    Planner → Coder → Reviewer → Coder(修复)
  mode=parallel  Planner → [Coder1, Coder2, ...] → Reviewer

请求体：
  {
    "requirement": "实现冒泡排序和二分查找",
    "mode": "serial",        // serial 或 parallel
    "n_coders": 2,           // 并行 Coder 数量（1-5）
    "with_fix": true         // 串行模式是否执行修复步骤
  }
```

**Java 类比：** Spring `@PostMapping` + `@RequestBody` DTO。

### 1.2 GET /chat/progress — 进度查询

```
GET /chat/progress           → 列出所有任务
GET /chat/progress/{task_id} → 查询单个任务进度
```

当前用内存 dict 存储（`_orchestrate_tasks`），非持久化方案，教学目的。

## 二、全局异常处理器（AOP）

```python
# 等价于 Spring 的 @ControllerAdvice
@app.exception_handler(asyncio.TimeoutError)
async def timeout_handler(request, exc):
    return JSONResponse(status_code=504, content={"detail": "请求超时"})

@app.exception_handler(Exception)
async def general_handler(request, exc):
    traceback.print_exc()  # 打印堆栈
    return JSONResponse(status_code=500, content={"detail": "..."})
```

注册后，所有端点不需要自己写 `try/except`——异常自动被对应的 handler 接管。

**Java 对照：**

| FastAPI | Spring |
|---------|--------|
| `@app.exception_handler(TimeoutError)` | `@ExceptionHandler(TimeoutException.class)` |
| 装饰器直接挂在 app 上 | `@ControllerAdvice` 独立类 |
| 手动调用注册函数（可选独立文件） | 包扫描自动发现 |

**改前 vs 改后：**

```python
# 改前：每个端点手写 try/except
@app.post("/chat")
async def chat(request):
    try:
        agent = create_agent()
        answer = await asyncio.wait_for(...)
        return ChatResponse(answer=answer)
    except TimeoutError:
        raise HTTPException(504, "超时")
    except Exception as e:
        raise HTTPException(500, str(e))

# 改后：端点只写业务逻辑
@app.post("/chat")
async def chat(request):
    agent = create_agent()
    answer = await asyncio.wait_for(...)
    return ChatResponse(answer=answer)
    # TimeoutError → 全局 handler → 504
    # Exception   → 全局 handler → 500 + 堆栈日志
```

## 四、Java 对照表

| Python | Java |
|--------|------|
| `@app.exception_handler(TimeoutError)` | `@ControllerAdvice` + `@ExceptionHandler` |
| `Pydantic BaseModel` | `@RequestBody` DTO |
| `async def` + `await asyncio.to_thread(...)` | `@Async` + `CompletableFuture.supplyAsync()` |
| `asyncio.wait_for(coro, timeout)` | `future.get(timeout, unit)` |
| `JSONResponse(status_code=504)` | `ResponseEntity.status(504).body(...)` |
| 模块级 dict 做状态存储 | 简化版 ConcurrentHashMap |
