## 依赖管理

```bash
# 完整依赖列表见 requirements.txt
# 当前依赖：
#   openai          — LLM API 调用（OpenAI 兼容协议）
#   python-dotenv   — 加载 .env 环境变量
#   fastapi         — HTTP 接口框架
#   uvicorn         — ASGI 服务器

# 安装（首次）
uv pip install -r requirements.txt

# 添加新依赖
uv pip install <package>
uv pip freeze > requirements.txt  # 注意：仅导出项目直接依赖
```
