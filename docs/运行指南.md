## 常见问题

### uv 缓存权限错误

```bash
# 错误：部分缓存文件属 root，无写入权限
# 解决：使用临时缓存目录
export UV_CACHE_DIR=/tmp/uv-cache
```

### .env 未加载

```bash
# 确认 .env 文件存在且包含有效 Key
cat .env
# 格式：DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

### .venv 不可用

```bash
# 重新创建虚拟环境
uv venv .venv
source .venv/bin/activate
uv pip install -r requirements.txt
```
