|---|------|------|---------|

| 7 | token 估算 | `memory.py` | 区分中英文：中文×0.7 + 英文×0.25（原来统一 /4） |
| 8 | 全局 agent 隔离 | `api.py` | 全局实例→工厂函数 `create_agent()` 每请求创建 |

### 修复验证

```

#1 验证：calculator("__import__('os').getcwd()") → ❌修复前: 返回路径  ✅修复后: ValueError 拦截
#2 验证：search_knowledge("python") → ❌修复前: dict  ✅修复后: 格式化文本 "[python]: ..."
#9 验证：/chat 端点改为 async def → 请求正常返回 HTTP 200
```

### 决策记录

- eval 安全选择了"正则白名单 + 受限命名空间"而非 ast.literal_eval()，因为后者不支持四则运算
- token 估算用 Unicode 范围判断中文（\u4e00-\u9fff 等三个区间），而非引入第三方库
- 健康检查端点不再依赖全局 agent，改为检查 LLMClient 的 API Key 可用性
- `/chat/reset` 端点保留但返回提示信息"每请求已隔离，无需手动重置"
