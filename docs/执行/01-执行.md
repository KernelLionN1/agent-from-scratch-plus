## 执行步骤

### 1. Python 环境确认

```bash
python3 --version
# Python 3.10.12 (系统)
```

WSL 自带的 Python 3.10.12 可用，但缺少 `python3-venv` 且无 sudo 权限。

### 2. 切换到 uv 包管理

```bash
uv --version
# uv 0.11.7 (x86_64-unknown-linux-gnu)
```

uv 已安装在 `/home/nith/.local/bin/uv`，无需 sudo，自带 venv 创建能力。

### 3. 创建虚拟环境

```bash
cd /mnt/d/ws/local/agent-from-scratch-plus
uv venv
```

自动下载 CPython 3.11.15，创建 `.venv/`。

### 4. 安装依赖

```bash
source .venv/bin/activate
uv pip install openai fastapi uvicorn python-dotenv httpx
```

安装 22 个包（含传递依赖）：

| 包 | 版本 | 用途 |
|---|------|------|
| openai | 2.41.1 | DeepSeek API 调用（兼容 OpenAI SDK） |
| fastapi | 0.137.1 | Web API 框架 |
| uvicorn | 0.49.0 | ASGI 服务器 |
| pydantic | 2.13.4 | 数据校验 / 模型定义 |
| python-dotenv | 1.2.2 | 读取 .env 环境变量 |
| httpx | 0.28.1 | 异步 HTTP 客户端 |

> ⚠️ uv 缓存目录 `/home/nith/.cache/uv/` 部分文件属 root，通过 `UV_CACHE_DIR=/tmp/uv-cache` 绕过。

### 5. 环境变量配置

| 文件 | 说明 |
|------|------|
| `.env` | DeepSeek API Key 配置（已加入 .gitignore，不会提交） |
| `.env.example` | 模板文件，可提交到仓库供参考 |

`.env` 内容：
```
DEEPSEEK_API_KEY=your-api-key-here   ← 需手动替换为真实 Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

### 6. .gitignore

排除 `.env`、`__pycache__/`、`.venv/`、IDE 配置等。

### 7. 每日计划文档

生成 `01-计划.md` 到项目根目录，涵盖 Day1 四阶段任务清单。

# 阶段一：基础 LLM 调用 + 自定义工具

> 时间：2026-06-16  |  产出：`src/llm_client.py`、`src/tools.py`、`test_phase1.py`

## 创建文件

### src/llm_client.py

封装 DeepSeek API 调用，通过 `python-dotenv` 读取 `.env` 配置。

- `LLMClient.chat(messages, tools, ...)` → 返回 `{"content", "tool_calls", "model", "usage"}`
- `_parse_tool_calls(message)` → 从 OpenAI Response 中提取 function_call
- 刻意不加重试/超时逻辑（后续阶段补充）

### src/tools.py

全局工具注册表 + 两个内置工具：

| 工具 | 功能 | 刻意踩坑点 |
|------|------|-----------|
| `calculator` | eval() 执行数学表达式 | 不校验参数，直接 eval（安全性+健壮性漏洞） |
| `search_knowledge` | 知识库子串匹配 | 返回 dict 非字符串；搜索逻辑简陋；描述模糊 |

## 测试结果（test_phase1.py）

```
测试 1 ✅ 纯文本对话
  输入: "1+1等于几"
  输出: "1+1 等于 2"
  tokens: 62

测试 2 ✅ 带工具调用（计算器）
  LLM 自动调用: calculator({"expression": "123 * 456"})
  工具结果: 56088

测试 3 ⚠️ 文本查询（踩坑见效）
  LLM 调用: search_knowledge({"query": "FastAPI 是什么"})
  工具结果: {}  ← 空dict！子串匹配 find("fastapi 是什么", "fastapi") → False
  坑点: 模糊描述 + 简陋搜索 + 不友好的返回值
```
