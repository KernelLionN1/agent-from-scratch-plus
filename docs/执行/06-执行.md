## 阶段一：技术收尾（4h）

> 状态：✅ 完成  |  时间：2026-06-17  |  测试：7/7 ✅

### 1.1 重量压缩升级 → 增量锚点

`src/memory.py` — 从全量重压缩改为增量模式：
- 新增 `_anchor_summary` / `_anchor_msg_count` 追踪已压缩进度
- `compress_heavy()` 只压缩锚点之后的新消息，合并到已有摘要
- 新增 `reset_anchor()` 重置状态
- 模式：首次全量，后续增量（Factory.ai 方案）

### 1.2 Streaming 流式输出

- `src/llm_client.py` — 新增 `astream()`，用 LangChain `astream_events()` 逐 token 产出
- `src/dynamic_agent.py` — 新增 `astream()`，手动循环 + 流式 LLM + 工具执行

### 1.3 MEMORY.md 文件持久化

`src/memory.py` — 新增 `FileMemoryStore`：
- `save(key, value)` / `load(key)` / `delete(key)` / `list_keys()`
- 存储到 `data/MEMORY.md`，跨会话保留
- 格式：`- key: value` 简单可读

### 1.4 回调机制

`src/callbacks.py` — `CallbackManager`：
- 8 种事件类型（AGENT_THINKING/TOOL_EXECUTING/COMPRESS 等）
- `on(event, handler)` / `off(event)` / `emit(event, **data)`
- `wrap(logger)` 一键注册 6 个常用回调到 Python logging
