**刻意踩坑清单**（已标注在 `docs/计划/02-计划.md`，Day3 统一修复）：

| 坑点 | 阶段 | 说明 |
|------|------|------|
| 消息重复消费 | 一 | 不设消息去重，同一消息被多个 Agent 重复处理 |
| 角色 Prompt 边界模糊 | 一 | 写模糊的角色定义，观察 Agent 越权行为 |
| 任务拆分不合理 | 二 | 不约束 Planner 拆分粒度 |
| 执行顺序混乱 | 二 | 不设依赖检查，Reviewer 可能在 Coder 完成前执行 |
| 无等待逻辑 | 三 | 不写 await，主线程直接退出 |
| 输出格式不统一 | 三 | 各 Agent 返回格式不一致导致汇总失败 |
| 全局变量滥用 | 四 | 各 Agent 直接改全局 dict，不加锁 |
| 状态错乱 | 四 | 并发时 A 读到的状态被 B 覆盖 |
